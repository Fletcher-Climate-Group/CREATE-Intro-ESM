# Dev Only Notes:

## Building the notebook after edits:
To see what the notebook will look like when publish clone or fork the repository and build the book

command for building the full book:
```
jupyter-book build mybookname/
```
After running this, the command will give you a file path to place in your browser to see the full html preview

## Publishing the notebook:
Once the notebook is public, we can publish it using github pages following the instructions here: https://jupyterbook.org/en/stable/start/publish.html
